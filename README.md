# Find Easily · Buy Easily

Busca de anúncios de **carros, motos e barcos** por características. O comprador diz o que procura, o site consulta os portais de anúncios de confiança e mostra todos os resultados em um só lugar, com link direto para o anúncio original.

## Versão de teste

Site estático (HTML + CSS + JS, sem dependências). Para ver, abra `index.html` no navegador.

- `index.html`: estrutura das páginas (busca, resultados, como funciona, fontes, confiança)
- `styles.css`: visual escuro, luxuoso e minimalista (dourado + tipografia serifada)
- `data.js`: fontes consultadas e **anúncios fictícios** de demonstração
- `app.js`: filtros, busca por texto livre, ordenação, filtro por fonte e animação da busca
